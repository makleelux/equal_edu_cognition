This is the data documentation for main analyses reported in th paper <<Can equalizing education weaken the link between parental education and
cognitive function? Evidence from a non-parametric decomposition analysis>> published in Social Science and Medicine.

The repository contains R code to 
* 01 prepare and 02 impute the longitudinal RAND files available from the HRS data portal (https://hrsdata.isr.umich.edu/)
* 03 conduct the decomposition analysis
* RMD prepare figures and result tables published in the manuscript

To set up the project, code files expect 
* input data sets (HRS files) to be stored in a subdirectory /infile in which intermediate data sets (created during preprocessing) will be stored, too
* an empty /output subdirectory, in which results and output files will be stored during computation
