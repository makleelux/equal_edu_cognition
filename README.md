This is the data documentation for the paper <<Can equalizing education weaken the link between parental education and
cognitive function? Evidence from a non-parametric decomposition analysis>> published in Social Science and Medicine.

The repository contains R code to 
* prepare the longitudinal RAND files available from the HRS data portal (https://hrsdata.isr.umich.edu/)
* conduct the decomposition analysis
* prepare figures and result tables published in the manuscript
